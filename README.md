# 🌐 Nueva Página Ruben

Proyecto web moderno iniciado con **Django**, **React**, y **Tailwind CSS**, combinando la potencia del backend de Python con la flexibilidad del frontend de JavaScript.

> ⚠️ Actualmente, el proyecto está enfocado únicamente en el **frontend (React + Tailwind CSS)**.  
> El backend en Django ha sido eliminado temporalmente para simplificar el desarrollo y despliegue.

---

## 🚀 Tecnologías utilizadas

### 💻 Frontend

- [React](https://reactjs.org/) – Librería de interfaces de usuario.
- [Tailwind CSS](https://tailwindcss.com/) – Framework CSS utilitario.
- [Framer Motion](https://www.framer.com/motion/) – Animaciones fluidas.
- [Axios](https://axios-http.com/) / `fetch` – Comunicación con APIs externas.
- [Vite](https://vitejs.dev/) (si lo usas) – Herramienta de build y desarrollo rápido.
- [npm](https://www.npmjs.com/) – Gestión de dependencias.

### 🖥️ Backend (removido temporalmente)

- **Django** – Framework backend en Python.
- **Django REST Framework** – Creación de APIs RESTful.
- **PostgreSQL** – Base de datos relacional.
- `pipreqs` / `pip` – Gestión de dependencias.

> 🔌 **API funcional anterior:**  
> http://127.0.0.1:8000/api/proyectos/  
> _(Actualmente deshabilitada)_

## ⚙️ Instalación y ejecución

1. Clona este repositorio:

   ```bash

   ```

## Scripts Utiles

- npm start # Inicia el servidor de desarrollo
- npm run build # Genera la versión optimizada para producción
- npm run dev # (si usas Vite) Inicia con Vite
